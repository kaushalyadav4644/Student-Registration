A web-based student registration application that enables students to register smoothly by submitting personal, academic, and login details. It streamlines the admission process, ensures accurate data collection, and provides an intuitive, user-friendly interface.

---

## 🚀 Features

* **Comprehensive Form Input:** Collects personal information, academic history, and secure login details.
* **Interactive Interface:** Built with clean HTML5, CSS3, and dynamic JavaScript for instant validation and user feedback.
* **Streamlined Admission Process:** Designed to make student enrollment fast and efficient.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (`index.js`, `style.css`)
